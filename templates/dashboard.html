📘 Project Abstract

The AI Phishing Detection Site is a cybersecurity-based web application developed to identify phishing threats from URLs, emails, general text content and uploaded files. The system combines machine learning classification with rule-based security checks to generate a threat score and risk category. It includes admin authentication, scan history management, CSV/PDF export and a public privacy-safe deduction report. The project demonstrates practical application of artificial intelligence, web development, database management and cybersecurity principles suitable for an MCA postgraduate capstone project.

🎯 Project Objectives

1. Threat Identification

Detect phishing attempts from websites, emails, copied content and uploaded files.

2. AI-Based Decision

Use machine learning with feature extraction to classify suspicious digital inputs.

3. Risk Scoring

Generate threat score and risk level such as Low, Medium or High.

4. Admin Monitoring

Provide secure admin access to view history, export reports and manage records.

5. Privacy Protection

Keep public reporting safe by hiding sensitive scan records and user inputs.

6. Academic Demonstration

Present a complete MCA-level applied AI and cybersecurity solution.

🏗 System Architecture

The project follows a modular architecture where each detection module sends extracted features to the decision layer. The final result is stored in SQLite and viewed through admin-protected pages.

1
User Interface

Bootstrap-based web pages for URL, Email, Content and File modules.

2
Feature Layer

Extracts URL, email, text and file-based security features.

3
Decision Layer

Combines ML prediction with rule-based security scoring.

4
Storage Layer

Stores scan history, risk level and login records in SQLite.
